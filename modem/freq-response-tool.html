Это устройство проигрывает ступенчатый свип-сигнал () через динамик. На втором устройстве откройте эту же страницу, выберите «Приёмник», нажмите «Начать запись» — и только потом здесь жмите «Играть свип».

Микрофон не активен
Замеров в серии: 0
Приём можно не останавливать между запусками свипа на передатчике — каждый новый синхро-тон засчитывается как следующий замер в той же серии. Останавливать запись нужно, только когда закончили всю серию; сохранить файл можно в любой момент, даже не останавливая приём.
Свип начинается с короткого двухтонового синхро-маркера (250 + 3200 Гц одновременно, по краям диапазона теста), за которым идёт набор одиночных тонов по возрастанию частоты. Приёмник слушает через микрофон, по паре маркера привязывает свою временную шкалу к передатчику, и для каждой тестовой частоты запоминает пиковую громкость только в её ожидаемом временном окне — случайный шум за пределами этого окна на результат не влияет.

Результат — относительная АЧХ канала: 0 дБ = самая громко принятая частота, всё остальное показано как ослабление относительно неё.
